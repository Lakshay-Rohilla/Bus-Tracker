# SGT Univerity Bus Tracker

Real-time bus tracking system for SGT University Route 43.  
Live location on Google Maps, driver info, and status updates.

🔴 Live demo: [https://lakshayr.pythonanywhere.com/](https://lakshayr.pythonanywhere.com/)

---

## Features

- Live Google Map with bus location
- Auto‑follow map (centers on bus)
- Driver name & phone number
- BUS STATUS: RUNNING / STOPPED
- Admin panel (view active viewers)
- Mobile responsive

## Tech

- Flask (Python)
- Google Maps API
- SQLite
- HTML/CSS/JS
